# TamaKaki 🐾

### A virtual pet game for the UwU Core track

TamaKaki is a browser-based virtual pet game inspired by modern Tamagotchi devices. Care for your digital pet, watch it grow, and experience the joy of virtual companionship!

**Built for the UwU Core track at Delulu Hackerhouse Hackathon**

### Features:
- 🐣 Raise your pet from baby to elder
- 🎮 Simple, intuitive gameplay
- 🎨 Pixel art graphics
- 🏠 Pet care mechanics (feeding, cleaning, playing)
- 📱 Works in any modern browser

### How to Play:
1. Open the game in your browser
2. Watch your pet hatch and grow
3. Take care of its needs (hunger, happiness, cleanliness)
4. Enjoy the journey!

### Technical Details:
- Pure JavaScript (no build system required)
- HTML5 Canvas graphics
- Offline-capable with Service Worker
- Local storage for save data

## 🏆 PayNet Award Demo

This project includes a **PayNet integration demo** featuring Malaysia's digital payment ecosystem:

### PayNet Features:
- **DuitNow QR Payment Simulation** - Realistic QR code generation with EMV-compliant data structure
- **Multiple Payment Methods** - DuitNow QR, Online Banking, and FPX integration demos
- **Transaction Analytics** - Comprehensive payment history and analytics dashboard
- **Real Banking Flow Simulation** - Bank selection, authentication, and payment confirmation
- **Receipt Generation** - Downloadable transaction receipts with PayNet branding

### How to Test PayNet Demo:
1. Click the **"PayNet Demo"** button (green button in bottom-left corner)
2. Experience the full payment flow with realistic Malaysian banking interfaces
3. Simulate successful/failed payments to see complete transaction handling
4. View analytics dashboard with transaction history and spending insights

### Technical Implementation:
- EMV-compliant QR code generation following DuitNow standards
- Realistic transaction ID generation and tracking
- Multi-bank authentication simulation (Maybank, CIMB, Public Bank, etc.)
- Complete payment lifecycle from initiation to completion/failure
- Transaction data persistence and export functionality

### For Judges:
This is a hackathon demo showcasing a complete virtual pet experience with **PayNet integration for gaming monetization**. The game demonstrates real-time pet simulation, sprite animation, user interaction patterns, and Malaysia's digital payment ecosystem integration.
